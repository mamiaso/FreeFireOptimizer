# Free Fire Optimizer

Android ve Windows için .NET MAUI uygulaması.

## Gereksinimler
- Visual Studio 2022
- .NET MAUI workload
- Android SDK (Android için)
- Windows 10/11 (Windows hedefi için)

## Çalıştırma
1. `FreeFireOptimizer.csproj` dosyasını Visual Studio ile aç.
2. Hedef platformu Android Emulator veya Windows Machine seç.
3. Build ve Run yap.

Not: Hassasiyet değerleri başlangıç önerileridir; oyun içinde test edilerek ayarlanmalıdır.
